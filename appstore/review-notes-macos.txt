VERSION 1.2.3 (macOS)

BibleText is a Bible reader. No account, login, or registration is required. Reading, search, navigation, notes, and cross-references do not require an AI-provider key. Downloaded scripture remains readable and searchable offline; network-backed downloads and optional provider services require connectivity when used.

This is the first Mac App Store release. It is built from the same 1.2.3 codebase as the iOS app on this record; these notes describe what is specific to the Mac.

STUDY GESTURE ON THE MAC
Selection actions live on the right-click menu rather than a touch popover. Select any passage in the reading pane and right-click: the menu offers the system's Copy and Look Up, Cross-references, a Share submenu (Share with citation, Share as image, Share as link, Share with note), and — only when an AI provider is configured — a Study with AI submenu (Explain, Analyze context, Analyze translation). Settings → Assistant defaults to None, so no AI items appear and no AI setup is required for review.

APP SANDBOX AND THE ONE-TIME MIGRATION
The Store edition runs in the App Sandbox. On the first launch that creates its container, macOS moves the preferences of an existing directly downloaded BibleText install (notes, settings, reading position) into the container, via the container-migration manifest bundled in the app. It is a local file move performed by macOS; nothing is transmitted anywhere. On a machine with no prior BibleText install there is nothing to move and the app simply starts fresh — the migration has no visible surface during review.

KEYS AND TRANSLATIONS
The App Store binary intentionally contains an obfuscated, link-time-injected API.Bible fallback used only to fetch the licensed New King James Version. A reader can replace it with their own API.Bible key. The NKJV text itself is fetched from API.Bible and is not packaged in the app or published on the website.

No AI-provider key is bundled. The optional Study with AI features stay off until the reader enters their own provider key in Settings → Assistant. That key is stored on the device and requests go directly to the selected provider.

The full WEB, WEB Catholic, and BSB texts are fetched and cached at runtime. The only embedded scripture is a small WEB Gospels seed used to show readable text immediately on first launch; the embedded Gospel-parallels dataset contains references rather than another full translation.

SHARED NOTES — HOW TO TEST
Shared notes are the one place the app displays text written by another person.

To send: select a verse, right-click, choose Share with note, type a short message, and pass on the resulting ordinary https://bibletext.co.uk link.

To receive on the Mac: paste the link into Notes or Messages and click it there — with BibleText installed it opens in the app, the passage with the message beside it (the app claims the domain via Universal Links). A URL typed into the browser address bar intentionally opens the website, per standard Universal Links behaviour. Pasting the link into the app's search box also opens it.

PRIVACY: the message is encoded in the URL fragment and travels only through whatever channel the sender chose. There is no server, account, user directory, or developer copy. The fragment is not sent to the website host. A received message is rendered as plain text with neutral attribution, never as markup or in the app's voice. The recipient can delete one note, delete all notes in Settings, or disable notes entirely.

HOW TO EXERCISE 1.2.3
Open any Gospel passage; with Words of Jesus enabled (Settings → Reading) the spoken words are red, following each translation's own publisher markings — the 1.2.3 change. Select a verse and right-click to see the selection menu described above. The audio button narrates the World English Bible and Berean Standard Bible with complete human recordings; the NKJV and the deuterocanonical books are read by on-device speech instead.
