VERSION 1.2.24

BibleText is a Bible reader. No account, login, or registration is required. Reading, search, navigation, notes, and cross-references do not require an AI-provider key. Downloaded scripture remains readable and searchable offline; network-backed downloads and optional provider services require connectivity when used.

WHAT CHANGED IN THIS BUILD
AI Settings now uses a compact supporting note, leaving more room for the controls.

HOW TO EXERCISE 1.2.24
Open Settings and look below the AI key controls to see the compact supporting note.

Reading, sharing, notes and cross-references need no AI setup. In World English Bible, select a heading word before Genesis 4:17: sharing cites the following verse without quoting the heading, and the selection offers no Study with AI. Select Scripture to use study. With a provider key in Settings → Assistant, choose Explain. Not now sends nothing; Allow remembers permission for that key. Changing or clearing the key withdraws it.

CURRENT NAVIGATION
Read, Books, and Search sit at the bottom on iPhone and iPad held upright. Held sideways, both move the same three destinations to a rail on the left; an iPad window in Split View or Stage Manager follows its own shape, with the rail while it is wider than tall. On iPhone the Read tab reads full-screen sideways, so the rail shows on Books and Search. Books is a grouped Old Testament / New Testament grid.

SHARED NOTES — HOW TO TEST
Shared notes are the one place the app displays text written by another person.

To send: open any chapter, press and hold to select a verse, choose Share with note, type a short message, and share it through any app. The result is an ordinary https://bibletext.co.uk link.

To receive: tap the link. The app opens the passage with the message beside it. Opened in a browser, the link shows the passage and note on bibletext.co.uk; where the website does not carry a translation's text, it shows the note with the reference, public-domain parallels, and a route into the app.

PRIVACY: the message is encoded in the URL fragment and travels only through the sender's chosen messaging app. There is no server, account, user directory, or developer copy. The fragment is not sent to the website host. A received message is rendered as plain text with neutral attribution, never as markup or in the app's voice. The recipient can delete one note, delete all notes in Settings, or disable notes entirely.

KEYS AND TRANSLATIONS
The App Store binary intentionally contains an obfuscated, link-time-injected API.Bible fallback used only to fetch the licensed New King James Version. A reader can replace it with their own API.Bible key. The NKJV text itself is fetched from API.Bible and is not packaged in the app.

No AI-provider key is bundled. AI answers require the reader’s own provider key, stored in the device Keychain; requests go directly to that provider. Choose None in Settings → Assistant to hide AI features. Core reading needs no AI setup.

The full WEB, WEB Catholic, and BSB texts are fetched and cached at runtime. The only embedded scripture is a small WEB Gospels seed used to show readable text immediately on first launch; the embedded Gospel-parallels dataset contains references rather than another full translation.
